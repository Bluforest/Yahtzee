YAHZTEE.PY
‾‾‾‾‾‾‾‾‾‾
Our Python program for this project is called yahtzee.py. It can be run from the command line of any computer with the latest version of Python installed.

______________________
HOW TO USE OUR PROGRAM
‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
The use of our program is done entirely within the command line terminal. The program will print instructions to the user whenever necessary.
In general, interfacing with the program involves entering numbers or words into the command line to make selections in the menus, choose which dice you wish to reroll in the game, and choose which score category you'd like to use at the end of your turn.

WHAT WENT INTO MAKING IT
‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
Programming the game itself mostly involved mapping the rules of Yahtzee onto computer instructions. _________________
KNOWN LIMITATIONS
‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
The game can only be played by four players, and the instructions are not always entirely intuitive. The testing we've done on the game with people unfamiliar with the program has always involved extensive time spent explaining the controls and rules.

Additionally, since there are no animations, it's difficult to tell if a die was rolled and landed on the same number or if it wasn't rolled at all. Given more time, it would be interesting to experiment with text deletion to see if making a die-rolling animation could be possible.

_____________
SOMETHING NEW
‾‾‾‾‾‾‾‾‾‾‾‾‾
Library or technique not learned in class: Python class functionality.

For Yahtzee to work in Python, a lot of information about the state of each player's game must be stored and accessed regularly. To help facilitate this, we created a class named ScoreCard that holds each player's score in every category in the game, as well as functions to update that player's score. This class also has a dictionary that maps specific strings with score update functions, so that a user's input in the command line while running the function can be passed directly into the program for the right function to run. If the user doesn't enter a string held within the dictionary, the resulting error is caught and the user is re-prompted.

Strategy and Code

Mastery of Data Types 
We used integers, strings, Booleans, and lists where applicable.
